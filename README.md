# jin_linktree — 전유진 가수 채널 모음 (텐텐 비공식 응원 페이지)

가수 전유진의 공식 채널(유튜브·인스타·음원·팬카페·티켓 등)을 한 곳에 모은 **팬 자율 비공식 응원 페이지**입니다.

위치: C:\Personal\jin_linktree\

## 파일 구성

- [index.html](index.html) — 메인 페이지 (채널 모음 카드)
- [press_kit.html](press_kit.html) — 전유진 가수 프로필 · 자료 모음 (디스코그래피·평판 지표·대표 무대)

두 파일 모두 의존성 없이 더블클릭으로 즉시 미리보기 가능합니다.

## 인터넷에 올려서 카페에 공유하는 방법 (Netlify Drop, 5분)

로컬 HTML 파일은 본인 PC에서만 열리므로 **인터넷에 올려야 다른 회원이 클릭만으로 볼 수 있습니다**. 가장 쉬운 방법은 Netlify Drop입니다.

### 단계

1. 웹브라우저로 [app.netlify.com/drop](https://app.netlify.com/drop) 접속 — **회원가입 없이도 임시 사용 가능**
2. `C:\Personal\jin_linktree` 폴더를 통째로 페이지 위로 **드래그 앤 드롭**
3. 약 30초~1분 후 임시 URL 생성됨 (예: `https://amazing-name-12345.netlify.app`)
4. 그 URL을 카페 게시글에 링크로 안내

### 임시 URL을 영구로 만들고 싶다면

업로드 후 Netlify 계정 가입(이메일만) → 그 URL을 본인 계정에 귀속 → 영구 보존. 무료.

### 다른 호스팅 옵션

- **GitHub Pages**: 무료, GitHub 계정 필요. URL: `username.github.io/jin_linktree`
- **Vercel**: 무료, 빠른 배포
- **자체 도메인** (예: jin1010.com): 도메인 등록비 필요

## 톤 / 운영 원칙

- **팬이 자발적으로 만든 비공식 응원 페이지**임을 푸터에 명시
- 가수에 관한 모든 권리는 본인과 소속사에 있음
- 소속사·가수 본인이 변경/내림을 요청하면 즉시 응함
- 비즈니스·협업 문의 정보는 노출하지 않음 (소속사 공식 채널을 통해서만)
- 평판 지표는 출처(한국기업평판연구소 brikorea.com)를 본문에 명시
